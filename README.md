A modern, feature-rich snake game built with React, featuring multiple game modes, achievements, leaderboards, and real-time multiplayer capabilities.

## ✨ Features

### Game Modes
- **Classic Mode** - Traditional snake gameplay with wall collisions
- **Transparent Mode** - Snake wraps around screen edges
- **VS AI Mode** - Challenge computer opponents with adjustable difficulty
- **Multiplayer Mode** - Local multiplayer for up to 4 players

### Key Features
- 🎮 **Responsive Controls** - Smooth keyboard and touch controls
- 🏆 **Achievement System** - Unlock 50+ achievements
- 📊 **Leaderboards** - Global and mode-specific rankings
- 👤 **User Profiles** - Track your stats and progress
- 🎨 **Modern UI** - Beautiful gradient designs with animations
- 📱 **Mobile Responsive** - Optimized for all screen sizes
- 🔥 **Firebase Integration** - Real-time data sync and authentication
- 🌙 **Offline Support** - Play even without internet connection
- 🎵 **Sound Effects** - Engaging audio feedback
- ⚡ **Performance Optimized** - Smooth 60 FPS gameplay

## 🚀 Quick Start

### Prerequisites
- Node.js 16.x or higher
- npm or yarn package manager
- Firebase account (for authentication and data storage)

### Installation

1. Clone the repository
2. Install dependencies: npm install
3. Copy .env.example to .env and configure Firebase
4. Start dev server: npm run dev
5. Open http://localhost:3000

## 🎮 Controls

**Single Player**: Arrow Keys or WASD | Space (pause) | R (restart)
**Multiplayer**: P1-WASD, P2-Arrows, P3-IJKL, P4-Numpad
**Mobile**: Swipe to move

## 📦 Built With

- React 18.2 + Vite 5.0
- Tailwind CSS + Framer Motion
- Firebase (Auth + Firestore)
- React Router + React Hot Toast
